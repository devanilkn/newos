## Decisions made in this session

1. **Purpose** — newos is an OS for running applications generated by AI agents, not humans. The core assumption being challenged is that OS design has always assumed a human developer in the loop.

2. **Monorepo** — all components live in a single repository because they are tightly coupled. The loader depends on the kernel ABI; the sysmaker ties everything together; design decisions span all components.

3. **Six top-level components** — `kernel`, `loader`, `sysmaker`, `ui`, `docs`, `design`.

4. **`design/` vs `docs/`** — `design/` holds architecture decisions, specs, and RFCs (the *why* and *how*). `docs/` holds user and developer documentation (the *what to do*).

5. **`design/architecture/overview.md`** — the initial overview document (written in the first commit) was moved here as the first architecture document.

6. **Language question raised but not decided** — Rust was suggested for `kernel` and `loader`; the question remains open.
